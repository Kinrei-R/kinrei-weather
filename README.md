### Kinrei — Weather Dashboard
A high-end, responsive weather application designed with a minimalist aesthetic and glassmorphism UI. This project provides real-time weather updates for any location worldwide, utilizing the Open-Meteo API for accurate atmospheric data.

### ✦ Features

    Dynamic Search: Instant location suggestions and geocoding to find any city, town, or village.
    
    Geolocation Integration: One-click access to local weather using browser-based GPS data.
    
    48-Hour Detailed Forecast: A horizontal timeline showing temperature trends and precipitation probability.
    
    Advanced Metrics: Real-time tracking of wind speed, humidity, visibility, and "feels like" temperatures.

    Sophisticated Design: A dark-mode interface featuring custom typography and subtle grain textures.

### 🛠 Tech Stack

    Frontend: Vanilla JavaScript (ES6+), HTML5, CSS3.
    
    API: Open-Meteo (Weather data) & Nominatim (Reverse Geocoding).
    
    Typography: Google Fonts.
